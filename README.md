# SUR Lab

Small, free tools for working across borders, at [lab.madebysur.com](https://lab.madebysur.com).
No cookies, no tracking, no sign-up.

Built with Astro and Tailwind CSS, hosted on Vercel.

## Run it locally

pnpm install
pnpm dev

Then open http://localhost:4321.
